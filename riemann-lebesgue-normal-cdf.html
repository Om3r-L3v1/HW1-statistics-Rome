Exercise 1 · Riemann and Lebesgue integrationPartition the domain or partition the range

§1The two definitions and how we compute them

Both approaches add up "height × width". They differ in what they cut into pieces.

Riemann

Split [a, b] into subintervals of width Δx, pick a point ξi in each and add f(ξi)Δx. The function is Riemann-integrable if all these sums approach the same number as the subintervals get smaller, whatever points are picked. Equivalently, the upper and lower sums (using the sup and inf of f on each piece) have the same limit.

Numerically we use the midpoint rule: N equal pieces, ξi in the middle of each. Cost: N evaluations of f.

Lebesgue

Split the range of f into levels y0 < y1 < … and, for each level, measure the set of x where f is above it. For f ≥ 0 this gives the "layer cake" formula:

∫ f dx = ∫0∞ μ{x : f(x) > y} dy ≈ Σj (yj+1 − yj) · μ{f > ȳj}

where μ is the length (Lebesgue measure) of the preimage and ȳj is the middle of the level band. We compute μ in two ways:

  • exact preimage: from the inverse of f when it is known (for sin x/x by bisection), K levels;
  • sampled preimage: count the fraction of M = 100,000 grid points where f is above the level, after sorting the M values once.

For the unbounded function 1/√x the levels go from 0 to 1 in one band and then grow geometrically up to K, so a few levels can cover a very large range of values. This is one of the practical advantages of partitioning the range.

    §5Pathological functions: Dirichlet and Thomae

    Here the two definitions really differ. A computer cannot help directly, because every floating-point number is a rational number, so the rationals and irrationals have to be handled exactly.

    Dirichlet: 1 on rationals, 0 on irrationals

    Every subinterval contains rationals and irrationals, so the sup of f on each piece is 1 and the inf is 0. The upper Riemann sum is always 1 and the lower sum is always 0, for every N. A Riemann sum gives 1 with rational tags (e.g. the midpoints) and 0 with irrational tags (e.g. midpoint + √2/(10N)). There is no common limit: the function is not Riemann-integrable.

    For Lebesgue the level sets are simple: for 0 ≤ y < 1, {f > y} = ℚ ∩ [0, 1], which is countable and has measure 0. All the slabs have zero width, so the Lebesgue integral is 0, the same as for the constant 0, which differs from f only on a set of measure 0.

    Evaluating Dirichlet(x) with floating-point numbers would return 1 everywhere, because doubles are fractions with a power-of-two denominator. The table below therefore tracks whether each tag is rational instead of evaluating f on a double.

    Thomae: 1/q at x = p/q, 0 on irrationals

    Thomae's function is discontinuous at every rational and continuous at every irrational. For any ε > 0 only finitely many points have f(x) > ε (those with q < 1/ε), so the upper sums can be made as small as we want: it is Riemann-integrable with integral 0. The lower sums are always 0 because every piece contains irrationals.

    To compute the upper sum exactly we need the sup of f on each piece [i/N, (i+1)/N], that is 1/q for the fraction with the smallest denominator q in the piece. We find it with the Stern–Brocot (continued fraction) search, using only integers. The Riemann sum with rational midpoint tags (2i+1)/(2N) uses gcd to reduce each fraction.

    For Lebesgue, {f > y} is a finite set for every y > 0, so it has measure 0 and the Lebesgue integral is 0 at once, with no limit needed.

      §7Why Φ has no elementary formula

      An elementary function is built from polynomials, exp, log, roots and trigonometric functions with finitely many operations and compositions. Liouville's theorem shows that no such function has derivative e−x²/2.

      Liouville's theorem (1835, in the form used by Rosenlicht). Let f and g be rational functions, g not constant. Then ∫ f(x)eg(x) dx is an elementary function if and only if there is a rational function R with f = R′ + R·g′. In that case ∫ f eg dx = R eg.
      1. Set up. For the normal density take f = 1 and g = −x²/2, so g′ = −x. An elementary antiderivative would need a rational R with R′ − xR = 1.
      2. R has no poles. If R had a pole of order k ≥ 1 at some point c, then R′ would have a pole of order k + 1 there, while xR has a pole of order at most k. The pole of R′ cannot be cancelled, so R′ − xR would have a pole, but 1 has none. So R is a polynomial.
      3. No polynomial works. If R ≠ 0 has degree d, then xR has degree d + 1 and R′ has degree d − 1, so R′ − xR has degree d + 1 ≥ 1 and cannot be the constant 1. R = 0 gives 0 ≠ 1.
      4. Conclusion. There is no such R, so ∫ e−x²/2 dx is not elementary. Φ is not elementary either: if it were, its derivative φ would have the elementary antiderivative Φ.

      This does not mean the antiderivative does not exist. It exists (φ is continuous), it is just not one of the elementary functions. The notes on Hogg, McKean and Craig §3.4 make the same point: there is no elementary antiderivative, but there is one as a power series, which can be integrated term by term. In practice, they use a z-table of Φ (Table II).

      §8The error function

      Instead of looking for a formula, we give the integral a name and study it as a new function.

      erf(z) = (2/√π) ∫0z e−t² dt      Φ(x) = ½ [1 + erf(x/√2)]

      The second formula follows from substituting t = s/√2 in the integral of φ and using Φ(0) = ½. It is an exact representation: Φ is erf, shifted and scaled. erf is a special function with known properties: it is odd, entire, has a power series that converges for every z, and has a simple asymptotic behaviour for large z.

      The name does not give us digits, though. To get a number such as Φ(1.96) = 0.97500… we still need an algorithm that evaluates erf, and every library does this numerically: with series, continued fractions or rational approximations fitted to a target accuracy. The question then becomes which algorithm is accurate and fast over the whole real line, including the tails where Φ is very close to 0 or 1.

function series(x) {
  let term = x, sum = x;
  for (let k = 1; Math.abs(term) > 1e-17 * Math.abs(sum); k++) {
    term *= x * x / (2 * k + 1);
    sum += term;
  }
  return 0.5 + pdf(x) * sum;
}

function upperTail(x) {
  let f = x, C = x, D = 0;
  for (let k = 1; k < 500; k++) {
    D = 1 / (x + k * D);
    C = x + k / C;
    f *= C * D;
    if (Math.abs(C * D - 1) < 1e-16) break;
  }
  return pdf(x) / f;
}

function normalCdf(x) {
  if (x > 2.5) return 1 - upperTail(x);
  if (x < -2.5) return upperTail(-x);
  return series(x);
}

      The series comes from integrating by parts repeatedly, or from multiplying the erf series by ez². The continued fraction is evaluated from the top with Lentz's algorithm, so the number of terms does not have to be fixed in advance. It needs fewer terms the further x is in the tail, which is exactly where the series would lose accuracy for negative x.
