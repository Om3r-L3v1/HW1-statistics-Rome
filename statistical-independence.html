Are X and F independent?

We take a bivariate dataset of two categorical variables X and F, count it into a contingency table, compute marginal and conditional frequencies, and compare the observed counts with the counts we would expect if X and F were independent. The chi-square statistic and its p-value measure how far the data are from independence. The main example is the Titanic passenger and crew list (X = class, F = survived); a simulated independent dataset and your own data can be loaded for comparison.

§1Independence in probability and in statistics

What we are testing, before we look at any data.

In probability

Two events A and B are independent if P(A ∩ B) = P(A)·P(B). When P(A) > 0 this is the same as P(B | A) = P(B): knowing that A happened does not change the probability of B.

Two discrete random variables X and F are independent if this holds for every pair of values:

P(X = xi, F = fj) = P(X = xi) · P(F = fj)  for all i, j
⇔ P(F = fj | X = xi) = P(F = fj)  for all i, j

So under independence the joint distribution is the product of the marginals, and every conditional distribution of F given X is the same as the marginal distribution of F.

In statistics

With data we only see frequencies. If nij is the number of records with X = xi and F = fj, ni· and n·j the row and column totals and n the total, independence means that the joint relative frequency should be close to the product of the marginal ones. In counts:

Eij = ni· · n·j / n   expected count under independence
χ² = Σi,j (nij − Eij)² / Eij,  df = (r − 1)(c − 1)

Under the null hypothesis H0: "X and F are independent", χ² approximately follows a chi-square distribution with df degrees of freedom when the expected counts are not too small (the usual rule is Eij ≥ 5). A large χ² means the observed table is far from what independence predicts. The test can reject independence; it can never prove it.

function contingency(records) {
  const xs = [...new Set(records.map(r => r.x))];
  const fs = [...new Set(records.map(r => r.f))];
  const O = xs.map(() => fs.map(() => 0));
  for (const r of records) O[xs.indexOf(r.x)][fs.indexOf(r.f)]++;
  return { xs, fs, O };
}

function chiSquare(O) {
  const rows = O.map(r => r.reduce((a, b) => a + b, 0));
  const cols = O[0].map((_, j) => O.reduce((a, r) => a + r[j], 0));
  const n = rows.reduce((a, b) => a + b, 0);
  const E = O.map((r, i) => r.map((_, j) => rows[i] * cols[j] / n));
  let chi2 = 0;
  O.forEach((r, i) => r.forEach((o, j) => chi2 += (o - E[i][j]) ** 2 / E[i][j]));
  const df = (O.length - 1) * (cols.length - 1);
  const p = 1 - jStat.chisquare.cdf(chi2, df);
  return { rows, cols, n, E, chi2, df, p };
}
