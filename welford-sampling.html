Exercise 1 · Welford's recurrence formulasDerivation for the mean, the sum of squares and the variance, and the code

§1Knuth's recurrence for the mean

The mean of the first k values can be updated from the mean of the first k − 1 values, without keeping the data.

Let Mk = (x1 + … + xk)/k be the mean of the first k values. The sum of the first k values is kMk, and it is the sum of the first k − 1 values plus the new one:

kMk = (k − 1)Mk−1 + xk
Mk = Mk−1 + (xk − Mk−1)/k   with M0 = 0

So the new mean is the old mean moved towards the new value by 1/k of the gap Δ = xk − Mk−1. We use the same idea for the sum of squares: write Sk in terms of Sk−1 and the new value.

§2Welford's recurrence for the sum of squares and the variance

Sk = Σi≤k (xi − Mk)² is the sum of squared deviations from the current mean. The sample variance is sk² = Sk/(k − 1).

  1. Shift the mean. With Δ = xk − Mk−1, Knuth's formula gives Mk = Mk−1 + Δ/k. So for every old value, xi − Mk = (xi − Mk−1) − Δ/k, and for the new value, xk − Mk = Δ − Δ/k = Δ(k − 1)/k.
  2. Old values. Expanding the square and summing over i = 1 … k − 1:
    Σi<k (xi − Mk)² = Sk−1 − (2Δ/k)·Σi<k(xi − Mk−1) + (k − 1)Δ²/k²
    the middle sum is 0, because deviations from their own mean add up to 0
    = Sk−1 + (k − 1)Δ²/k²
  3. New value. (xk − Mk)² = (k − 1)²Δ²/k².
  4. Add them.
    Sk = Sk−1 + (k − 1)Δ²/k² · (1 + (k − 1)) = Sk−1 + (k − 1)Δ²/k
    and since (k − 1)Δ/k = xk − Mk:
    Sk = Sk−1 + (xk − Mk−1)(xk − Mk)   with S0 = 0
  5. Variance. Dividing by k − 1 gives the sample variance. Written as a recurrence of its own (k ≥ 2):
    sk² = Sk/(k − 1) = (k − 2)/(k − 1) · sk−1² + Δ²/k
    the population variance is Sk/k

Every step only needs the previous M, the previous S and the new value, so the data never has to be stored or read twice. Each update also works with deviations from the current mean, which avoids the loss of precision of the one-pass formula Σx² − (Σx)²/k when the values are large.

§3The code

The three highlighted lines are the whole algorithm. The rest is setup and the final division.

function welford(scores) {
  let k = 0, mean = 0, ss = 0;
  for (const x of scores) {
    const d = x - mean;
    mean += d / ++k;
    ss += d * (x - mean);
  }
  return { n: k, mean, ss, variance: k > 1 ? ss / (k - 1) : NaN };
}

§4The score distribution and the experiment

Each penetration attempt gets a score from 0 to 10, drawn independently from a fixed distribution with mean μ and variance σ². Every hacker attacks n systems, so it has a trajectory of n scores, and Welford's code gives its sampling mean x̄ and sampling variance s².
